# docs

AB Test and Target Harness の手順書。製品の機能と制約、構成図、前提、導入の流れ、開発用コマンドとディレクトリは [製品 README](../README.md) にある。

## 手順書

### 導入する

1. **構成を選ぶ。** AI エージェントに任せる場合は、[導入の質問](install-questions.md)に沿って、やりたいことと今の環境を伝える。手で進める場合や判断の根拠を知りたい場合は、[導入構成の選び方](install-patterns.md)を読む。ドメインに応じた edge の置き方 3 種類、Free と Workers Paid の上限と目安、control の守り、付加機能の要件、入力ファイルの対応を確認できる。入力にはリポジトリ直下の[雛形](../deploy-answers.example.yaml)を使う。
2. **Cloudflare にデプロイする。** [デプロイガイド](deploy.md)に沿って、自分のアカウントに edge / control / admin を配置する。KV / D1 / R2 / DO / secrets と Cache Rule の設定から初回セットアップまでを扱う。導入後の更新順序、無認証入口の防御、非常時の入り方、稼働の確認、バックアップ・復旧・撤去もこのガイドにある。
3. **サイトにタグを設置する。** [サイト導入ガイド](site-install.md)の最短手順チェックリストから始める。第 1 部はサイト作成、タグ設置、GA4 と GTM の接続(GTM インポート用 JSON あり)、設置後の確認とトラブル対処。第 2 部は consent、Mode C と Mode B、履歴条件、コードの変更と CSP。第 3 部でサイト設定項目、dataLayer の契約、ブラウザの制約、外部送信規律を参照できる。

### 運用して結果を読む

| やりたいこと | 読むガイドと内容 |
|---|---|
| エクスペリエンスを運用する | [運用ガイド](operations.md)。ライフサイクル、下書きプレビュー、公開の反映、開始直後のチェック。ロールと管理操作(操作の記録を含む)、レート制限の実効、既知の制約と課題、トラブルシュート、使用状況(Cloudflare の上限)、テストの結果の記録、画像の一覧も扱う。 |
| GA4 / BigQuery で分析する | [分析ガイド](analytics.md)。計測できる項目、カスタム定義と BigQuery の事前設定、レシピの取得、GA4 探索レポート(方式 A)、BigQuery(方式 B)、GA4 Data API、結果の読み方。 |
| 管理画面でテストの結果を読む | [テスト結果の読み方](experiment-results.md)。評価計画と評価時点、判定の 5 つの状態と数値、データ品質(割り振りの偏り・混在・適用の失敗・収集の失敗と停止)、終了と採用・複製、記録の設定と保持。管理画面の「?」にもこの文書の説明が表示される。 |

### AI エージェントに運用を任せる

導入・運用・分析の流れを確認したら、[エージェント向けガイド](agent-guide.md)で鍵の範囲と権限、API キー、操作時の制約を確認する。正式な版はこのリポジトリにあり、control が `GET /llms.txt` でも配布する。

ガイドには 8 本のレシピがある。エクスペリエンスの作成から公開まで、下書きの検証、結果の読み取り、配信条件の what-if、オーディエンス、使用状況の監視、複製、操作の記録と変更履歴を扱う。
